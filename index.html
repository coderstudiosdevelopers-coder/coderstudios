Coder Studios가 앱을 만드는 방식

✓ 계정 없이 바로 씁니다

메모·가계부·다이어리에 적은 내용은 회원가입 없이 기기 안에 저장됩니다. 앱별 자세한 처리 내용은 각 앱의 개인정보처리방침에서 확인하실 수 있습니다.

✓ 문의에 이틀 안에 답합니다

영업일 기준 2일 이내에 답변드립니다. 자동응답이나 상담 봇을 쓰지 않고, 개발자가 직접 읽고 답합니다.

✓ 만들고 끝내지 않습니다

새 OS 버전이 나오면 대응하고, 스토어 리뷰와 메일로 받은 의견은 다음 업데이트에 반영합니다.
